# Seashell Mod

## Description
The Seashell Mod adds various types of small 3D seashell blocks to tropical beaches in Minecraft. It is designed for Minecraft 1.21.1 and uses NeoForge 21.1.265. The mod includes a configurable density setting to adjust the frequency of seashells in the world.

## Installation
1. Download the mod jar file.
2. Place the jar file in the `mods` folder of your Minecraft instance.
3. Launch Minecraft with NeoForge 21.1.265.

## Use
1. After installation, start a new world or use an existing one.
2. Explore tropical beaches to find seashell blocks.
3. Adjust the density of seashells by editing the config file at `config/seashellmod-common.toml`.

## Configuration
The mod includes a config file located at `config/seashellmod-common.toml`. You can adjust the density of seashells in the world by changing the `seashell_density` value (0.0 to 1.0).

## Features
- Adds small 3D seashell blocks to tropical beaches.
- Configurable density of seashells.

## Building
To build the mod, run `./gradlew build` in the project root. The mod jar will be generated in the `build/libs` directory.
